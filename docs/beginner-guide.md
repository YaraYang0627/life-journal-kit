# 小白上手教程

按下面的步骤，先体验演示，再开始记录自己的生活。

当前版本建议使用 Mac，需要能操作本地文件的 Codex 和 Python 3.9 或以上。Windows 原生暂不支持。工具免费开源，AI 服务使用自己的账号和额度。基础使用不需要飞书。

## 1. 下载工具

打开 [下载页面](https://github.com/YaraYang0627/life-journal-kit/releases/tag/v0.1.0-preview)，找到 **Assets／资源**，点击 **Source code (zip)／源代码（zip）**。

下载后双击解压。保留整个文件夹，里面应该有 `README.md`、`scripts`、`viewer` 等文件和目录。

## 2. 在 Codex 中打开文件夹

打开 Codex，添加本地项目或打开文件夹，选择刚才解压的整个工具文件夹，在这个项目里开始对话。

把下面这段话复制进去：

```text
请先读取这个项目的 AGENTS.md 和 README.md，检查 Python 是否为 3.9 或以上。
我第一次使用，请运行自带的虚构演示，并打开生活地图。
演示数据放在源码文件夹旁的新目录中，不覆盖已有文件。
不读取我的私人资料，不接飞书，不设置定时任务。
如果缺少运行条件，请简单告诉我需要做什么。
```

看到地图后，可以切换月份、点开某一天查看日记。这里展示的都是虚构示例。

## 3. 建立自己的日记目录

演示能正常打开后，继续发：

```text
请读取 .agents/skills/life-journal/SKILL.md，按这个 Skill 帮我记录日记。
在工具文件夹旁建立独立的 my-journal 数据目录，时区用 Asia/Shanghai。
如果目录已存在，先检查，不要覆盖或重新初始化。
不要混入演示数据。请告诉我日记保存在哪里。
```

如果你不在中国时区，请把时区换成自己的；不清楚时可以让 Codex 帮你确认。

## 4. 记录当天发生的事

把下面的日期和内容换成自己的，再发送：

```text
使用 life-journal，继续使用我的 my-journal 数据目录。
请记录 [YYYY-MM-DD] 的日记。
今天发生的事：[填写自己的经历]
我当时的感受：[有就写，没有可以省略]
还没完成或只是计划的事：[有就写，没有可以省略]
先给我看初稿，不要自动定稿，也不要补写我没说过的细节。
```

不用写成作文，几句话也可以。线下经历需要自己补充，工具不会自动知道。

## 5. 核对后保存，更新地图

先看初稿，有错误直接告诉 Codex 修改。尤其检查日期，以及“准备做的事”有没有被写成“已经做完”。

确认没问题后发送：

```text
可以定稿。请保存终稿，更新生活地图，并打开给我看。
```

只有确认后的日记才会进入地图。以后每天继续在同一个项目、同一个数据目录里记录，不需要重新下载工具。

## 6. 月底生成回顾

积累日记后，把月份换成你要回顾的月份，再发送：

```text
使用 life-journal，继续使用我的 my-journal 数据目录。
请根据 [YYYY-MM] 已确认的日记生成月度回顾，保留来源。
没有记录的日子不要补写，不编造感受或成果。
展示回顾供我核对，并更新生活地图。
```

月度回顾需要你发起请求，基础版不会到月底自动生成。

## 使用时记住这几件事

- 记昨天的日记时，写清楚昨天的日期。
- 关闭预览或重启电脑后，让 Codex 重新打开地图即可，日记文件仍在原来的数据目录。
- 真实日记放在工具源码之外，不上传到这个公开仓库。云端 AI 可能处理你交给它的素材，同步盘也可能同步本地文件。
- 遇到报错，把错误提示告诉 Codex，请它解释并排查；不要公开发送真实日记或账号密钥。

先用顺上面的基础流程。如果之后想接入飞书工作总结和电脑定时运行，再看 [可选飞书与定时运行说明](real-capture.md)。这些功能需要另外配置，不会随下载自动启用。
